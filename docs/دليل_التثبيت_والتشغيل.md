# دليل تثبيت وتشغيل LEVEL7 Nesting

## 1. المتطلبات
- Windows 10 أو 11 بنظام 64-bit.
- لا يحتاج Python ولا GRAFIS ولا اتصال بالإنترنت؛ كل الاعتماديات مضمّنة في المثبت.

## 2. التثبيت
1. شغّل الملف `LEVEL7Nesting-0.1.0-Setup.exe` (يُنتَج من GitHub Actions ضمن Artifact باسم `LEVEL7Nesting-Setup`).
2. اختر لغة المثبت، ثم اترك خيار «إنشاء أيقونة على سطح المكتب» مفعّلًا.
3. اختياريًا: اربط ملفات المشاريع `.l7n` بالبرنامج.
4. بعد التثبيت تظهر أيقونة **LEVEL7 Nesting** على سطح المكتب وفي قائمة ابدأ.

> ملاحظة: Windows SmartScreen قد يحذّر لأن الملف غير موقّع رقميًا؛ اختر «مزيد من المعلومات ← تشغيل على أي حال».

## 3. المسار الأول: ملف MDL
1. افتح البرنامج واسحب ملف `.mdl` إلى النافذة أو استخدم «ملف ← فتح».
2. تبويب **القطع**: قطع الإنتاج تظهر أولًا ومفعّلة؛ قطع الإنشاء والمساعدات غير مفعّلة. عدّل عدد النسخ والمعكوسة لكل قطعة.
   - عمود **النسيج**: الزاوية المقروءة من الملف. إن ظهرت «غير معروف» يجب تحديدها يدويًا قبل النستينج.
3. تبويب **كميات المقاسات**: أدخل عدد القطع (الملابس) لكل مقاس.
4. لوحة **القماش والنستينج**: العرض الكلي، الهوامش، المسافة بين القطع، نوع الفرد، مجموعة الخامة (O = القماش الخارجي، F = البطانة)، النمط والزمن والبذرة.
5. اضغط **تشغيل النستينج** (F5). يعمل في الخلفية وتظهر أفضل نتيجة مرحلية؛ **إيقاف** يحتفظ بأفضل حل صالح.
6. عدّل يدويًا عند الحاجة: سحب القطعة بالماوس، `R` تدوير 180°، `P` تثبيت/فك تثبيت، `M` قياس مسافة، `Ctrl+Z`/`Ctrl+Y` تراجع/إعادة. أي تعديل يُتحقق منه فورًا وتُلوّن القطع المتداخلة أو الخارجة بالأحمر.
7. احفظ المشروع (`Ctrl+S`) ثم صدّر من قائمة **تصدير**.

## 4. المسار الثاني: ملف SCB
1. افتح ملف `.scb`؛ يظهر الماركر الأصلي كما في GRAFIS مع العرض والطول والكفاءة المسجلة.
2. غيّر العرض أو الكميات أو الإعدادات ثم شغّل النستينج؛ تبقى أبعاد القطع كما هي.
3. لوحة **النتائج** تعرض مقارنة الأصلي بالجديد (الطول، الاستغلال، الاستهلاك بالمتر والياردة).
4. احفظ نسخة جديدة؛ ملف SCB الأصلي لا يُعدّل أبدًا.

### مقابلة إعدادات GRAFIS
- Spreading type «Right - Left» = نوع الفرد «مفتوح» مع النسخ المعكوسة (الافتراضي).
- Bundle direction «Two way» = تفعيل «السماح بالدوران 180°»؛ «One way» = إلغاؤه.
- «Same sizes - same direction» غير منفذ بعد.
- قيمة U/B في GRAFIS تظهر في النتائج باسم «Per garment (U/B)».

### خيارات عرض الماركر (عرض ← خيارات عرض الماركر… أو Ctrl+D)
مثل نافذة Marker display options في GRAFIS:
- داخل القطع: الرموز، المقاس والمجموعة (مثل 44/A)، خط المسافة، خطوط العلامات (النوتشات)، خط النسيج، كل الخطوط الداخلية، أسماء القطع.
- عناصر مساعدة: علامة الكفاءة (خط أحمر عند نهاية الماركر)، الكفاءة السابقة (خط متقطع عند طول الماركر السابق)، لون أبيض للعلامات.
- طريقة عرض القطع: المحيط فقط / مصمتة / مصمتة مع المحيط، عتامة خلفية القماش، شفافية القطع، التلوين حسب المجموعة أو المقاس أو القطعة.
- شريط الحالة يعرض L و E و U/B و Wi بالمتر أو بالملليمتر.
تُحفظ الخيارات تلقائيًا للمرة القادمة.

## 5. التصدير
- **PLT**: مقياس 1:1 (40 وحدة/مم افتراضيًا). من «إعدادات البلوتر» حدّد الأقلام لكل طبقة وتبديل المحاور والانعكاس. اطبع ملف `examples/calibration_1000mm_square.plt` وقِس المربع (1000 مم) قبل الإنتاج.
- **DXF**: وحدات مم وطبقات منفصلة: CUT, SEAM, INTERNAL, NOTCH, GRAIN, TEXT, MARK, BORDER.
- **ISO**: غير مهيأ لماكينة محددة بعد؛ يمكن إنتاج معاينة تشخيصية فقط (ليست للإنتاج).

## 6. حساب الاستغلال
الاستغلال = مساحة اتحاد القطع الموضوعة ÷ (عرض القماش × طول الماركر) × 100. يُعرض بالعرض الكلي وبالعرض الصافي. هذا التعريف يطابق قيمة EFFCNCY في ملف GRAFIS المرفق (83.86%).

## 7. أداة الفحص
`level7-cli.exe inspect ملف.mdl ملف.scb -o تقارير` تُنتج تقريرًا (JSON و Markdown) يفصل بين: مؤكد، مرجح، غير معروف، غير مدعوم.

## 8. سطر الأوامر
```
level7-cli.exe info "Neay blue pants.mdl"
level7-cli.exe nest "Neay blue pants-44.scb" --width 1500 --time 60 -o result.l7n
level7-cli.exe export result.l7n --format dxf -o result.dxf
```

## 9. البناء من المصدر (للمطورين)
على Windows مع Python 3.12 و Inno Setup 6: `powershell -File packaging\build_windows.ps1`.
